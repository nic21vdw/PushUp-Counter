OBS browser source

Add a Browser Source in OBS with this URL, 900×220, and tick “Shutdown source when not visible”. The page background is already transparent — no custom CSS needed.

Tweak with query params: size (px), color, label, align (left/center/right), font, weight, shadow=none, subs=1 to show the sub line, numberonly=1 for just the number.

OBS camera source

A second Browser Source, 1280×720, that shows your webcam with the pose skeleton on it and counts reps at the same time — so OBS never needs a Video Capture Device for this camera. Only one page should count at a time; this URL does, so close the camera page before going live.

cutout=1 removes the background so you float over your scene, bg=00ff00 puts a chroma-key colour behind you instead, video=0 leaves just the skeleton, skeleton=0 hides it, counter=0 drops the number, mirror=1 flips it, and count=0 makes it display-only.
